# Local-only inputs / 仅本地生成的输入

The original MoCa stories/questions are not distributed because no dataset redistribution license was identified in the pinned release. Supply the two original JSON files from a lawfully obtained local source, then follow the experiment README. The adapter checks their exact hashes.

原题不随仓库分发。自行合法取得来源后按实验 README 在本地生成 `dataset.json`；该文件被 Git 忽略，分享文件夹或压缩包前仍须移除。

Complete numerical model responses and aggregate reports are included. Recomputing agreement with human judgments requires the local source; reading the existing report does not.
