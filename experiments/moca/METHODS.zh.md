# MoCa — 方法

## 材料与权限边界

固定来源为 144 个因果故事、62 个道德故事。原始故事、问题、逐人投票和含题文请求没有放入本仓库。`preparation/code/prepare_data.py --source-dir` 只读取用户自行提供的本地来源，校验哈希、每题 25 个投票及 answer_dist，生成被 Git 忽略的 data/dataset.json。它不下载数据。公开报告只保留聚合统计及模型的 Yes/No 选择结果。

## 适配与判据

每题一个结构化 Yes/No 判断，没有原论文 few-shot/persona 或多模型条件。Jev P(Yes)>0.6 归 Yes，<0.4 归 No，其余归 Ambiguous；人类概率由 25 人投票得到并使用相同边界。0.4 与 0.6 本身均属于 Ambiguous。结构化概率不是人类比例。

三类一致性、明确题 AUROC、概率差异与按故事 bootstrap 区间均离线计算。因素可多重标注；分组均值差不是原论文 AMCE，也不是独立因果效应。分析脚本不会生成包含故事的 cases 文件。没有题文时仍可阅读公开汇总；完整重算需要在本地提供来源，不能把“可读取汇总”写作完整复现。

## 整合与复现

原评测使用独立脚本与历史预算控制；本次只迁移已完成结果。新的 config.yaml 是上游标准格式入口，不代表历史运行使用了统一 runner。response 对象保持原样，分析代码路径按主项目目录调整。复算命令见 README；没有新增付费调用、提示词变化或抽样。
