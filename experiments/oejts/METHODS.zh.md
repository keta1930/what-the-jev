# OEJTS 1.2 — 方法

## 材料与复现边界

OEJTS 1.2 由 Eric Jorgenson 发布；原 PDF 题目注明 CC BY-NC-SA 4.0。本仓库不分发问卷、题目两端原文、逐题请求或原 PDF；不包含官方 MBTI 题库。准备脚本仅从用户自行提供的本地 PDF/转录生成题目，并逐题核对历史输入哈希。数据目录及 raw 内容被忽略，发布检查在这些内容存在时拒绝通过。

## 历史协议与转换

每题以模型自评说明和五个位置呈现；32 题各自独立调用，连续十轮，没有对话上下文。historical import_manifest.json 记录 320 个原始文件哈希及 32 个输入哈希。转换仅将原记录的 response 装入上游 id/response/error 包装，模型响应原封不动；新 ID 在十轮中均为 oejts-q01 至 oejts-q32。config 的 repeat:10 对应 responses_1.jsonl 至 responses_10.jsonl。

## 计分

以下为对来源数值计分规则的独立实现；不复制问卷题文。Q 为 1 至 5 的所选位置。

```text
IE = 30 - Q3 - Q7 - Q11 + Q15 - Q19 + Q23 + Q27 - Q31
SN = 12 + Q4 + Q8 + Q12 + Q16 + Q20 - Q24 - Q28 + Q32
FT = 30 - Q2 + Q6 + Q10 - Q14 - Q18 + Q22 - Q26 - Q30
JP = 18 + Q1 + Q5 - Q9 + Q13 - Q17 + Q21 - Q25 + Q29
```

分数 >24 分别取 E/N/T/P，否则取 I/S/F/J。恰等于 24 也按此规则计字母，同时单独标记 boundary_axes。全选中间位置得到四个 24，对应 ISFJ。量表原为人类自评，包含生活经历措辞；此处只探索模型回答与重复计分的稳定性，不声称测出了心理人格。

## 整合与复现

原评测使用独立脚本与历史预算控制；本次只迁移已完成结果。新的 config.yaml 是上游标准格式入口，不代表历史运行使用了统一 runner。response 对象保持原样，分析代码路径按主项目目录调整。复算命令见 README；没有新增付费调用、提示词变化或抽样。
