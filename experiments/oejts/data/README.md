# Local-only questionnaire / 仅本地生成的问卷

The OEJTS 1.2 source questionnaire is CC BY-NC-SA 4.0 and is not distributed here. The adapter accepts a user-supplied local PDF or transcription, checks it against the historical input hashes, and creates Git-ignored `dataset.json`.

原问卷不随仓库分发。自行提供合法取得的来源，可在本地生成输入；分享整个文件夹或压缩包前须移除生成文件。

The included ten response files can be rescored without the questionnaire. This experiment is OEJTS, not the official MBTI.
