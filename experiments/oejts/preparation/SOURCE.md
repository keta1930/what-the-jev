## Materials deliberately excluded

The original PDF credits Eric Jorgenson and marks the questions [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). The noncommercial/share-alike questionnaire is not bundled into this MIT project. No PDF, endpoint text, raw questionnaire JSON, item requests or official MBTI materials are distributed. The source-file hash and historical input hashes are in import_manifest.json.

Only complete model responses without prompts, aggregated numerical scores, and independently implemented numerical scoring/preparation code are included. Numeric formulas are attributed in METHODS.md. Locally supplied original files remain subject to their own terms; generating a local dataset does not change those terms. The generated dataset is ignored and must be removed before distributing a directory archive.

The preparation script makes no download or model call. Access to the original source is needed for input-level reconstruction; excluded source material is not claimed as MIT-licensed.
