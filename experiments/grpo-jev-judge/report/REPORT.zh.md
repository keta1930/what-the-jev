# GRPO Rollout 判优：JEV 八选一并对照 LLM 判官

## 摘要

本实验测试 JEV 能否像 LLM 判官一样评判思维质量。场景是 150 道开放式推理题，每题配有同一模型采样的八条思考；DeepSeek LLM 判官已为每题选出一条赢家，JEV 要在八条中选出同一条。JEV 的命中率为 45.3%（95% 置信区间 37.6%–53.3%），远高于 12.5% 的随机水平但远未饱和；选择明显压向首位：34.0% 落在 R1，R8 仅被选 7 次。JEV 报告的 confidence 几乎无区分度：命中者均值 0.377，未命中者 0.285。把候选文本挪进 criteria 的变体布局命中率为 42.0%。标准布局消耗输入 1,020,099 token、输出 12,750 token，总费用 0.0428 美元。结论是 JEV 的八选一判断高于随机但带有明显的顺序偏差，适合做候选初筛，不能替代判官直接产出标签。

## 1 实验目的

本实验测 JEV 的多候选判优能力：在同一题目的八条思考中选出质量最好的一条。这个场景来自 GRPO 类强化学习的标注环节——组内 rollout 需要一个赢家信号，标注动作正是这次八选一。DeepSeek LLM 判官已按一份书面标准完成选择，本实验看 JEV 能否复现判官的选择。

### 与 dpo-jev-judge 的关系

同一批 rollout 与判官选择通向成对实验 dpo-jev-judge：那里每对由判官赢家加同题随机一条落选思考组成，JEV 二选一（见 experiments/dpo-jev-judge/report/REPORT.md）。两个实验测同一种判优能力的两个形态：组内八选一（本实验）与成对二选一（后者一致率 83.3%）。

## 2 数据集

数据集包含 150 道中文开放式推理题，场景取自日常生活。每题配有八条思考（R1–R8），由 Qwen3-0.6B 在 temperature 1.0 的思考模式下采样；各条只有推理过程、没有结论，顺序即采样顺序。DeepSeek 判官按一份书面质量标准——无矛盾、覆盖所问、可跟随、对象具体——为每题选出一条赢家，该赢家即参考答案；JEV 使用同一份书面标准作答。

题目按形式分三类：现象解释、原因排查、权衡建议，各 50 道。这一划分由本次分析从 id 前缀（g-causal、g-diagnosis、g-tradeoff）恢复，不是样本的原始标签。

每道题以两种布局呈现。标准布局把八条思考放在 `state.responses`，criteria 只放指向它们的指针；criteria-text 布局把思考文本直接作为 criteria，state 只留题目。

## 3 最小示例

本节取数据集中的一道题，展示一次完整的输入与输出（标准布局）。发给模型的输入如下（省略 model 字段）：

```json
{
  "state": {
    "prompt": "一位同事离职前留下一份交接文档，接手的职员照着文档操作却还是经常出错。请你解释为什么有文档交接仍然会出错。",
    "responses": {
      "R1": "好的，我现在要解决这个问题。用户说，一位同事离职前留了一份交接文档，接手的人照着操作却出了问题。用户想知道为什么还有这样的文档交接会出错，这可能是为什么。首先，我得考虑常见的原因。可能文档本身存在问题，比如不完整的，或者用词不当。……",
      "…": "……R2 至 R8 省略……"
    }
  },
  "questions": {
    "winner_overall": {
      "type": "choice",
      "instructions": "一、任务\n从 responses.R1 至 R8 中选出思维质量最好的一条。\n……（其余六节省略）",
      "criteria": {
        "R1": "responses.R1",
        "R2": "responses.R2",
        "…": "…",
        "R8": "responses.R8"
      }
    }
  }
}
```

模型输出如下（仅保留关键字段）：

```json
{
  "answers": {
    "winner_overall": {
      "type": "choice",
      "choice": "R5",
      "probabilities": {"R1": 0.07, "R2": 0.21, "R3": 0.09, "R4": 0.12, "R5": 0.43, "R6": 0.02, "R7": 0.04, "R8": 0.02},
      "confidence": 0.35
    }
  },
  "usage": {"input_tokens": 4872, "output_tokens": 85, "cost": 0.000204624}
}
```

JEV 选择了 R5，与 LLM 判官的选择一致。

## 4 结果

### 整体结果

150 题全部获得有效作答，无失败记录。以 DeepSeek LLM 判官的选择为判据——题目是开放式问题，没有标准答案，测的是与判官的一致性而非正确性——JEV 命中 68 题，命中率 45.3%，95% 置信区间 37.6%–53.3%。八选一随机作答的命中率为 12.5%。

### 按题型分组

三类题型的命中率有温和差异：

| 题型 | 题数 | 命中 | 命中率 |
| --- | ---: | ---: | ---: |
| 现象解释 | 50 | 27 | 54.0% |
| 原因排查 | 50 | 21 | 42.0% |
| 权衡建议 | 50 | 20 | 40.0% |

### 按选项位置分组

判官的赢家分布在全部八个位置上（最多的是 R1 占 19.3%、R6 占 18.7%），而 JEV 的选择明显压向首部（图 1）：51 次（34.0%）落在 R1，R8 仅被选 7 次（4.7%）。这一倾斜抬高了赢家恰好靠前的题目的命中率：判官赢家位于 R1 时 JEV 命中 21/29（72.4%），位于 R6 时仅命中 7/28（25.0%）。

![各选项位置上判官与 JEV 的选择分布](fig/zh/position-distribution.png)

图 1：判官的赢家散布各位置，JEV 的选择堆积在首位。

### 置信关系

JEV 对每题报告一个 confidence。命中率随 confidence 上升，但所有作答的 confidence 都压在不高的区间，最高档也远未接近可靠（图 2）：

| Confidence | 题数 | 占比 | 命中率 |
| --- | ---: | ---: | ---: |
| < 0.2 | 27 | 18.0% | 29.6% |
| 0.2–0.3 | 47 | 31.3% | 31.9% |
| 0.3–0.4 | 35 | 23.3% | 51.4% |
| 0.4–0.5 | 18 | 12.0% | 61.1% |
| ≥ 0.5 | 23 | 15.3% | 69.6% |

![按 confidence 分档的命中率](fig/zh/confidence-hit.png)

图 2：命中率随 confidence 上升，但作答集中在低 confidence 区，没有一档接近全对；虚线为 12.5% 随机水平。

作为信任信号，confidence 在这里几乎无区分度：命中者均值 0.377，未命中者 0.285，作答中位数 0.30，最高值仅 0.81。没有任何阈值能把可信判断筛出来。

### 行为统计

全部作答的概率合计均为 1。3 题（2.0%）的所选项不是概率最高的选项。

### 调用成本

标准布局共消耗输入 1,020,099 token、输出 12,750 token，总费用 0.0428 美元。

### 布局消融

两种布局只差候选文本的位置。把文本挪进 criteria 损失少量命中率，减弱但未消除顺序偏差，并整体压低 confidence：

| 布局 | 命中率（95% 置信区间） | R1 被选次数 | confidence 中位数 | 输入 token | 输出 token | 费用 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 标准布局 | 45.3%（37.6%–53.3%） | 51（34.0%） | 0.30 | 1,020,099 | 12,750 | 0.0428 美元 |
| criteria-text | 42.0%（34.4%–50.0%） | 25（16.7%） | 0.18 | 1,005,999 | 12,750 | 0.0423 美元 |

## 5 结论

作为八选一的思维质量判官，JEV 与 LLM 判官的一致性远高于随机——45.3% 对 12.5%——但选择带有明显的首位偏好，confidence 也无法区分判断好坏。在这条流水线里，JEV 的组内判断适合做候选初筛；正式标注应交给更强的判官，或改用 dpo-jev-judge 测试的成对形态。

## 6 洞察

1. JEV 在多候选判优时偏好靠前位置，候选列表越长越要打乱或轮换选项顺序。
2. 八选一场景下 confidence 几乎无区分度，不能用来筛选可信判断；要置信筛选应缩小候选集，而不是设阈值。
3. 长候选文本放在 state、criteria 用指针是更稳的布局：把文本塞进 criteria 会降低命中率并压低 confidence，没有换来好处。
4. 与判官的一致性远高于随机却远未饱和，JEV 在 rollout 标注中适合做候选初筛，不适合直接当标注器。
