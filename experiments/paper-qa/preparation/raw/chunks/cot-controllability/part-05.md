## E.1 Model Details

Olmo-3-RL-Zero. The Olmo-3 paper (Olmo et al., 2025) released checkpoints from ‘RL-Zero’ runs (runs that begin with the Olmo-3-7B base model) in different domains. We use checkpoints from the allenai/Olmo-3.1-7B-RL-Zero-Math and allenai/Olmo-3.1-7B-RL-Zero-Code training runs as examples of models that have undergone RL reasoning training. These have been trained against a rule-based verifier with a reference answer for math, and against a test-case verifier for coding. We also use the final allenai/Olmo-3-7B-RL-Zero-General model, which is trained against an LLM judge on general chat questions, as an example of a non-reasoning RL-Zero run (see Figure 10).

Olmo-3-Thinking. The Olmo-3-7B-Think and Olmo-3-32B-Think are reasoning models that have undergone a three-stage post-training recipe: supervised finetuning (SFT) on top of the Olmo Base model using reasoning traces generated by QwQ-32B and DeepSeek R1, followed by direct preference optimization (DPO) with paired completions from Qwen 3 32B (chosen) and Qwen 3 0.6B (rejected), and finally reinforcement learning with verifiable rewards (RLVR) on prompts spanning math, code, instruction following, and chat. We evaluate the Base model and the final SFT, DPO, and RL models.

Magistral-Medium. Magistral Medium is trained with pure reinforcement learning on top of Mistral Medium 3. Training uses 38k math problems and 35k code problems filtered for appropriate difficulty. Rewards combine formatting constraints, correctness verification (rule-based math checking and code test execution), length penalties, and language consistency signals. We run inference on the pre- and post-RL models using "magistral-medium-2506" via the Mistral API and "mistralai/mistral-medium-3" via OpenRouter.

OpenThinker. OpenThinker3-7B finetunes Qwen2.5-7B-Instruct via SFT on 1.2M reasoning traces generated by QwQ-32B across math, code, and science domains.

## E.3 Output Controllability Evaluations

We design simple output controllability evaluations for the Olmo-3 RL-Zero and Base model. Here, we attempt to balance between the following. (1) Maintaining equivalency to the CoT-Control evaluations. We use the same CoT-Control QA data sources: We use Information Addition and Stylistic Modification instructions that are very similar to the CoT-Control CoT controllability evaluations. (2) Adapting to the output space and weak controllability of these models: Since the model has no meaningful output space, we tell it to output its final answer in a sentence, and to comply with a constraint on this sentence. Since Information Suppression is not meaningful in this setting, we do not maintain these instructions. Since the models are poor at providing structured outputs, we use an LLM judge (gpt-5-mini-2025-08-07) to determine if the model has made a reasonable effort to complete the task. See our prompts to the models under evaluation in Figure 20 and our prompts to the LLM judge in Figure 21.

## G Reproducibility

Throughout the paper, for all the standard errors we report, if it is a percentage, the standard error is estimated as $\mathrm { S E } = { \sqrt { \frac { p ( 1 - p ) } { n } } }$ , assuming independent Bernoulli trials and via the Central Limit Theorem that p is normally distributed. Otherwise, we simply use the sample standard deviation divided by the square root of the sample size. For all our experiments where we use LLMs, we use greedy decoding unless noted that it is temperature sampling, in which case we set the temperature to 0.
