# E Per-Model SURF Results

SURF (Murray et al., 2026) was run on 55 high-priority (P1 and P2) Anthropic-constitution tenets across honesty (17 tenets), harm avoidance (13), hard constraints (10), epistemic autonomy (8), and wellbeing (7). Tenets within a section were grouped into a single shared rubric, so the search converges on whichever violation type is most reliably elicited within that section. We focused this analysis on the four most recent Claude variants (Sonnet 4.5, Sonnet 4.6, Opus 4.5, Opus 4.6); we did not run SURF on cross-spec comparison models for cost reasons. Each subsection below reports total confirmed violations, the sectionby-section breakdown of those violations, the dominant failure mode, and representative quoted outputs from confirmed violations.
