# SocialIQA — 方法

## 材料与适配

作者 v1.4 test 的 2,224 行完整保留；plain 与 withDims 版本的 test 标签逐行相同。`state` 保存 context/question，`answer` 为 A/B/C 三选一，原英文和顺序保持不变。来源标签置于独立 `data/reference.json`，不会传入请求。12 道固定 dev 调试题只用于接口核验，没有据此调优；调试结果与费用单列。

## 判分与相关性

按参考键逐题判断，正式分母 2,224。分析同时保留按有效回答计的准确率、Wilson 区间、去重后首次出现题目的准确率，以及按完整 context/question/options 重复题聚类的 bootstrap 区间（3,000 次，固定种子见分析脚本）。重复题没有从主结果中删除。九个 promptDim 分组是 ATOMIC 生成来源，改写后的题意可能不同，不当作九种已验证能力。正确率不是同理体验或道德人格测量。

## 历史费用

`attempts.jsonl` 包括 debug/test 的尝试；一次技术失败费用未知，保留 0.01 美元历史预留。正式成功结果仍完整保留。

## 整合与复现

原评测使用独立脚本与历史预算控制；本次只迁移已完成结果。新的 config.yaml 是上游标准格式入口，不代表历史运行使用了统一 runner。response 对象保持原样，分析代码路径按主项目目录调整。复算命令见 README；没有新增付费调用、提示词变化或抽样。
