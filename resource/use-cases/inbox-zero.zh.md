# Inbox Zero (elie222)

【定位】Inbox Zero 是 elie222 开发的开源邮件助手，GitHub star 数以千计，定位为 Fyxer 的开源替代；Jev 在产品中作为可选的分类后端之一。它也是 Jev 进入成熟生产型开源软件的案例。

【功能】覆盖收件箱整理、预起草回复、退订与归档、冷邮件拦截等邮箱日常分拣工作。整理与过滤类决策使用 Jev 原生返回的有界类别与 yes/no 概率，而不是还需解析、校验和采信的自由文本。

【特点】作为既有成熟产品接入 Jev 的案例：Jev 只接在分类决策这一个环节上，是多个可选后端之一，产品其余功能不依赖 Jev。

【适用】适合评估 Jev 生产可用性的读者研究真实产品中的集成方式，观察类型化输出落在分类决策点上的接法。它同时展示了类型化输出在真实集成中被消费的位置，以及产品如何使用收到的类别与概率。它是完整的邮件助手产品而非 Jev 专项演示，可参考的范围集中在分类后端的接入实现，而非整个产品。
