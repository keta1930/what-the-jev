# jev-tetris (thelau)

【定位】jev-tetris 是 thelau 的示范项目：用 Jev 玩俄罗斯方块，并对下棋过程做带对照组的测量。整个项目是一个紧凑、仪表齐全的决策层实验，考察 Jev 的强项与失效模式。

【功能】代码枚举当前方块的全部合法落点，把每个落点写成一句英语；五个 Choice 问题并行打分；棋盘实时渲染 Jev 的完整概率分布，而不只是最终落子。

【特点】自带三组对照："打乱概率"对照、El-Tetris 上界参照，以及一个 23 行的正则基线。在该项目的测量中，正则基线胜过了模型；README 列出了这一结果与项目的局限。

【适用】适合观察 Jev 概率分布行为与能力边界的读者：分布全程可见，对照设计可整体复用到其他决策模型的测试。由于全部合法落点都被枚举打分，任务全程可观测，模型看到的选项集与规则基线相同。其测量结果显示简单规则基线在该任务上超过 Jev，引用该项目时需连同此结论一并报告。
