# TypeSafe AI Official GitHub (SDKs, adapter, agent skills)

**Positioning** The `typesafe-ai` GitHub organization is the official home of TypeSafe AI's open-source tooling for Jev, the company's System One decision model. It is where the company publishes the components a project needs in order to integrate with the model beyond raw HTTP calls — the language SDKs, an adapter, and agent skills.

**What it does** The organization hosts the official Python and TypeScript SDKs, which wrap request construction, typed questions, and response handling into library calls. A separate repository, `system-one-adapter-python`, presents the System One interface as if it were an LLM provider, so Jev can be placed alongside generative models under a provider interface and compared side by side. An agent skills repository is hosted here as well, and the source behind the workflow evaluations shown at evals.typesafe.ai is published through the organization too.

**Characteristics** The Python SDK released version 0.7.0 on 2026-09-18. At the time of writing the two SDKs held roughly 270 stars each, the adapter 383, and the agent skills repository about 2.6k — snapshot figures all taken at one moment. The repositories see frequent updates, so exact names and paths should be confirmed on the organization page rather than from secondary write-ups, and star counts drift over time; any figure cited from here should carry its date.

**When to use** Draw on it when a project needs the official SDKs for Python or TypeScript, an LLM-provider-shaped adapter, ready-made agent skills, or the source of the evals.typesafe.ai workflow evaluations. Star counts and repository paths are time-sensitive snapshots: cite them with a date and verify them on the organization page, not from secondary write-ups.
