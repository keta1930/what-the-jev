# TypeSafe AI 官方 GitHub（SDK、adapter、agent skills）

【定位】`typesafe-ai` 是 TypeSafe AI 的官方 GitHub 组织，集中托管围绕其 System One 决策模型 Jev 发布的开源工具。要在裸 HTTP 调用之上做集成的开发者，从这里获取官方组件。

【功能】组织内提供官方 Python 与 TypeScript SDK，封装请求构造、类型化问题与响应处理。独立仓库 `system-one-adapter-python` 把 System One 接口包装成 LLM provider，可与生成式模型并排对比。另托管 agent skills 仓库；evals.typesafe.ai 工作流评测的源代码也发布于此。

【特点】Python SDK 于 2026-09-18 发布 0.7.0 版。撰写时两个 SDK 各约 270 星，adapter 仓库 383 星，agent skills 仓库约 2.6k 星，均为同一时点的快照。各仓库更新频繁，名称与路径以组织页为准，星数会随时间变化。

【适用】适合需要官方 SDK、LLM provider 形式的 adapter 或 agent skills 的 Jev 集成场景，也适合需要查看官方评测源码的读者。星数与仓库路径属于会漂移的快照，引用时注明时间，以组织页为准，不宜转引二手描述。
