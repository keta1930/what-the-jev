# 示例 README

`example/<name>/` 下的 `README.md` 按本文件写作。参考实现：`example/ticket-triage/README.md`。

读者没有读过数据集，也不会打开数据文件。README 要让他读完后知道：示例问模型什么、模型答了什么、代价多少、怎么重跑。

## Frontmatter

`README.md` 与 `README.zh.md` 各自以 YAML frontmatter 开头，三个字段缺一不可：

```yaml
---
title: 示例标题
date: YYYY-MM-DD
summary: 正文第一句
---
```

- `title` 写示例标题，与正文 H1 的文本相同。
- `date` 写最近修改日期，新建与每次修改都写当日。
- `summary` 写本示例测什么的一句话，与正文第一句的文本相同。

## 结构

按此顺序成文，无内容的节省略。

1. 示例目标：测什么，一句话；紧接一句给出样本规模。
2. 提问：逐条列出模型要回答的问题。每条给出问题本身（自然语言）、答案类型、答案形态。选项与等级这类封闭集合必须列全，文本抄自数据集。
3. 结果：按问题逐项给出判断。
4. 成本：输入与输出 token 数、费用。
5. 复现：可直接执行的命令。

## 约束

- 标识符保持原值。字段名、选项键、枚举值、答案类型名用代码格式原样写出，不译成中文。
- 引用数据原文。等级文本、选项描述直接抄 `data/dataset.json` 的 `criteria`，不改写、不翻译。
- 只给结果，不给推算。写结果值本身，不写得到它的算式。
- 结果要解读。说明模型判了什么、落在哪一档。逐字段复述响应不是解读，只摆数字不给判断也不是。
- 数值核自 `result/responses.jsonl`。不凭印象概括。字段随答案类型变化，例如 `noul` 不返回 `confidence`。
- 多样本示例写清样本量；给比例或分布时写清分母，以及失败样本是否计入。
- 书面语，无人称。不用「你」「我们」，不用口语。
- 不写读者无法据此行动的句子。模型内部实现、统计免责声明、「以上为一次真实响应」这类自我声明都不写。
- 并列内容用行或用表，不用分号串成长句。Markdown 中相邻行会并成一段，分行需用空行隔开。

## 交付前自检

逐条回答，任一为「是」则重写。

- 有句子只在复述响应，没有给出判断？
- 有标识符被译成中文，或有数据原文被改写？
- 给了算式、推算过程或单价？
- 数值未经 `result/responses.jsonl` 核对，或概括超出样本支撑？
- 出现「你」「我们」或口语词？
- 缺 frontmatter 字段，或 title 与 H1、summary 与正文第一句不一致？
